# 比较方法与公开依据

## 1. 冻结可检验的问题与比较口径

先从任务原文确定目标对象、研究范围、目标终点、判定方向、硬约束和使用场景。不同科学问题/目标效应的候选一般不直接排性能名次。明示推断是探索、试运行、验证性研究还是工艺筛选，不能在不同目的间机械套用功效、主终点或对照要求。

所有真实候选版本至少包含：

| 核心字段 | 需要核实的原始内容 | 禁止的自动补全 |
|---|---|---|
| 假设 | 科学/因果/测量/统计/执行假设，适用边界与验证状态 | 把经验或推测写成观察事实 |
| 变量 | 实验单位、因子、响应、协变量/干扰、单位、时点、方向和重复层级 | 技术重复变成独立样本；奇怪或空缺值变成统一常数 |
| 对照 | 比较基准、对照目的、留存的替代解释 | 一律加空白组；未说明当未实施 |
| 步骤 | 准备—处理—测量—分析、顺序、依赖、批次/重复、质控与异常路径 | 把另一实验室流程默认移植到本情景 |
| 参数 | 有限允许域、设备/任务约束、联合规则、来源和单位 | 交集变并集；任意中点；仅单轴合法当全组合合法 |
| 资源 | 设备、材料、技能、场地、机时、人机成本、排期、货期、审批及此刻状态 | 把文献资源存在当本情景可用；把规划价格当真实报价 |
| 判读标准 | 指标、方向、阈值、停止/异常/不确定规则，是否预设 | 看完结果再设阈值；“符合预期”当可检验判据 |

附加领域检查必须按场景触发。例如，活体动物规划才查设施、伦理、动物福利与人员条件；临床协议才按需查注册、招募与知情同意；因子可控且有响应时查水平范围、组合和确认运行。纯计算研究需比较模型、数值收敛、独立运行和数据隔离，不能把运行数写成“生物重复”。

## 2. 三道互不混淆的状态

- **信息来源**：`reported`（来源直述）、`derived`（机械复算）、`assumed`（显式工作假设）、`inferred`（相关性/外推判断）、`unknown`、`conflict`、`not_applicable`。
- **科学可行性**：`feasible`（有必需资料且硬门全过）、`infeasible`（已证实硬冲突）、`undetermined`（资料不足或冲突未解决）。每列保留理由与证据，不用一个布尔值吞掉未知。
- **实际运行**：`partial`、`failed`、案例允许的完成状态。文件不存在、文件未写、不可读、证据不足、工具失败、全部违约是不同情况。

**缺失不是零，未知不是否认，不适用不是缺失，缺乏证据不是证明无效。** 真实 `0` 和 `false` 必须保留原始的零值/假值语义。

### Source → Claim → Derivation → Decision

- Source：实际路径或 URI、稳定 ID、版本/DOI（实际有则）、SHA-256、来源角色（真实记录、先前研究或前瞻情景设定）。
- Claim：候选/版本、字段路径、原始文字/数值/单位、规范化过程、支持/反驳关系、适用范围与不确定性。
- Derivation：所有操作数 claim、单位/换算及其依据、公式、工具/实际版本、未舍入结果与呈现层舍入。
- Decision：硬门和验证结果、显式偏好及选择、每个舍弃理由、改选触发项。

PDF 定位包括物理页码（可另写印刷页码）、章节/表/图和精确短引。JSON 用 RFC 6901 Pointer；纯文本使用精确原文和行/字符位置。对于模糊短引加前后文。渲染或 OCR 是实际发生才能记录的派生活动。hash 仅识别字节，不是同行评议、真实性或因果结论的证明。

## 3. 成本、机时、人力和时间

案例中的资源/价格/预约契约是上游约束；如果题面明确是前瞻场景，必须保持“场景契约”身份。论文支撑科学步骤，不覆盖契约单价、货期或预约档期。

### 成本台账

每一费用行记录事件定义、实际收费次数、数量/单位、价格/币种、一次性或重复性、批次/共享规则、来源、基础或返工场景、及对应的完整公式。典型费用：

`总费用_i = 收费事件数_i × 每事件数量_i × 单价_i + 明确固定费用_i`

批量收费只有合同明示时使用：

`批次数 = ceil(需处理量 / 每批容量)`，`总费用 = 批次数 × 每批固定费 + 实际处理量 × 变动单价`

`recurrence` 和固定/变动属性不可混淆；一次性费用不能被按计划重复数无意多算，也不能为摊低成本而跨互斥候选共享。只有来源明确允许复用、分摊且确定分母时才做对应处理。

独立样品数、样本技术测量数、条件数、失败尝试数分开；不可据技术重复自动增加所有准备耗材或改写独立样本量。

### 排期台账

任务至少保留 ID、持续时长及其定义、依赖、人员/机器投入、物料到货、时窗和来源。

- 依赖终点before继承起点；独立并行分支不能相加，串行不能取最大；合作人数不能在未给效率条件时简单缩短日历工期。
- 等待采购、表征排队、审批等是显式阶段，不是隐藏的零。
- 校验预约时要看任务半开区间、实际可用日历和容量；不是把总机时与总时窗比较就能证明预约成功。
- 材料货期保留最早/最晚或指定离散情景，实际使用时点不得早于实际到货。未知时区、截止下单时间、日历边界或节假日不编造工作日结果。

返工只有显式场景/分布/独立假设时才计算概率或期望；否则分别列基础与条件返工情景，预算硬门槛要考虑合同要求的具体情景而非仅期望值。

## 4. 决策：约束不求平均分

1. **硬门**：目标必需资源、预算、有限参数、真实安全/伦理前提、给定审批与排期等逐项审查。每个必需状态都不能用整体高分抵消。
2. **可行域内同单位权衡**：比较原始数值、目标、风险、证据直接性与不充分信息；标记 Pareto 非支配，但非支配不自动产生唯一最佳。只有相关准则均已知且可比，才判定某方案的确定支配；实质冲突可标为 `incomparable`，关键字段缺失应标 `undetermined_missing`，不得把缺失当成不可比或性能相同。脚本在无共享优先级时不自动单选；若单元素 Pareto 前沿仍保留合理解释，Agent 可在明确全部目标、数据可比和约束覆盖后基于其仅剩的非劣性选择，多个非劣方案保留，展示顺序不是排名。
3. **明确偏好**：只使用任务给定的目标优先级、权重或效用。必要时固定外部参照点，不用当前候选集内部归一化悄悄制造顺序依赖。
4. **解释性敏感性**：自有依据的有限域/情景重跑价值，给条件改选或阈值；没有概率时不方差分解，不发明权重扰动范围。只有证据支持全枚举才说所有情景均通过。
5. **落选理由**：每个落选者都必须关联实际硬冲突、目标偏好或可核验的权衡；“综合得分较低”不是充分理由。

### 版本传播

只对明确声明前后版本的候选建立修订关系。先按稳定字段/步骤ID对齐，分别记录展示性差异、科学/资源/契约差异和无法配对。下游重新计算资源组合、时间、成本和选择。新文件或数组顺序不能证明科学偏好变化；不能把旧证据挪给新含义的字段。

### 全部不可行与信息不足

- 全部明确违约：推荐为“无合格候选”，列出各版本的已证冲突与最小需审批变更，但不擅自改规则。
- 全部未知：推荐为“无法确认选择”，列出最小补资料集合，不谎称“全不可行”。
- 证据不足和硬失败可以并存；分开呈现。

## 5. 方法依据

以下是调研所依据的原始或权威公开资料，并非案例数据来源：

- [Belton & Stewart, Multiple Criteria Decision Analysis (2002)](https://doi.org/10.1007/978-1-4615-1495-4)：先结构化目标、属性与价值；加权仅在明确价值尺度和替代率语义时考虑，不能直接把原始单位乘任意“重要程度分”相加。
- [Cinelli, Coles & Kirwan (2014)](https://doi.org/10.1016/j.ecolind.2014.06.011)：按数据类型、偏好、阈值、补偿程度、不确定性与可解释性选方法，不能宣称一种算法对所有科研选型最好。
- [Emmerich & Deutz (2018)](https://doi.org/10.1007/s11047-018-9685-y)：多目标非支配无需跨单位权重，亦不保证唯一最佳；少量离散候选可直接精确比较。
- [Martin & Mazzotta (2018)](https://doi.org/10.1016/j.ecoser.2017.10.022)：固定结果范围与随候选变化的局部尺度具有不同性质，防止增删候选改变原有价值尺度。
- [Mareschal (1988)](https://doi.org/10.1016/0377-2217(88)90254-8)：在实际给定模型与偏好域中研究选择稳定性问题；不能把稳定区间解释成成功概率。

- [Wilkinson et al., FAIR Guiding Principles (2016)](https://doi.org/10.1038/sdata.2016.18)：持久标识、限定引用及详细溯源。用于证据链，而不是只给整篇参考文献。
- [W3C PROV-DM](https://www.w3.org/TR/prov-dm/) 与 [PROV-O](https://www.w3.org/TR/prov-o/)：输入、活动、结果与修订关系。不能把血缘关系本身当作科学支持。
- [W3C Web Annotation, Text Quote Selector](https://www.w3.org/TR/annotation-model/#text-quote-selector)：精确原文与前/后缀定位；偏移位置依赖同一来源版本。
- [Sandve et al., Ten Simple Rules for Reproducible Computational Research (2013)](https://doi.org/10.1371/journal.pcbi.1003285)：每个结果保留产生过程、程序/版本、参数与输入。
- [Gorissen et al., A Practical Guide to Robust Optimization (2015)](https://doi.org/10.1016/j.omega.2014.12.006)：有不确定集合的约束稳健化。不提供集合来源就没有现实稳健保证。
- [Deb et al., NSGA-II (2002)](https://doi.org/10.1109/4235.996017)：多目标非支配概念；此 Skill 对三个已知候选直接比较，不调用遗传优化算法。
- [Cinelli et al., MCDA Index Tool](https://doi.org/10.1007/s10669-020-09784-x)：用于比较归一化、权重和聚合方法，提醒不要把综合得分当作不变事实；硬约束仍需先行审查。
- [BIPM JCGM 100:2008](https://www.bipm.org/documents/20126/2071204/JCGM_100_2008_E.pdf)：测量不确定度报告。缺资料或模型判断不得包装成测量标准差/概率。
- [NIST/SEMATECH e-Handbook, DOE](https://www.itl.nist.gov/div898/handbook/pri/section3/pri32.htm)：按目标、因子、响应与资源选实验设计，检查不可能因子组合；不把全因子当通用必需。
- [SPIRIT 2025](https://doi.org/10.1136/bmj-2024-081477)：临床协议报告的最小条目；它不替评价者规定科学设计，不硬套所有学科。
- [PREPARE](https://doi.org/10.1177/0023677217724823)：活体动物研究规划需覆盖人员、设施、经费、安全与质量；按具体物种和场景启用。
- [ARRIVE 2.0](https://doi.org/10.1371/journal.pbio.3000410)：实验单位、随机化、盲法、样本量与判读等动物研究透明报告。报告完整度不自动等于实验质量。
- [ICH E9(R1)](https://database.ich.org/sites/default/files/E9-R1_Step4_Guideline_2019_1203.pdf)：目标效应及假设偏离敏感性。通用借用“先定义比较对象，再比较方法”，不机械使用临床术语。
- [RFC 6901](https://www.rfc-editor.org/rfc/rfc6901)、[RFC 6902](https://www.rfc-editor.org/rfc/rfc6902)：JSON 路径与事务式变更，不证明科学语义等价。
- [Agent Skills Specification](https://agentskills.io/specification)：元数据、触发与渐进披露；本套算法和题面输入输出约束不是通用 Skill 规范的自带来源。

这些公开依据支持方法设计；实际案例结论只能来自运行时的真实输入、材料与明确契约。
